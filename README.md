# 🍔 BingeBite

<div align="center">

A modern and responsive food ordering web application built with **React**, **Vite**, and **Firebase**. BingeBite provides a seamless food discovery and ordering experience with an intuitive interface, restaurant browsing, cart management, and secure authentication.

![React](https://img.shields.io/badge/React-19-blue?logo=react)
![Vite](https://img.shields.io/badge/Vite-6-purple?logo=vite)
![Firebase](https://img.shields.io/badge/Firebase-12-orange?logo=firebase)
![License](https://img.shields.io/badge/License-MIT-green)

</div>

---

## ✨ Features

- 🍕 Browse restaurants and food items
- 🔍 Search and filter restaurants
- 📍 Location selection
- ❤️ Add and manage favourites
- 🛒 Shopping cart with quantity management
- 💳 Checkout interface
- 🔐 Firebase Authentication
- 📱 Fully responsive design
- ⚡ Fast performance powered by Vite
- 🎨 Modern UI with reusable React components

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/your-username/bingebite.git
```

### Navigate into the project

```bash
cd bingebite
```

### Install dependencies

```bash
npm install
```

### Start the development server

```bash
npm run dev
```

Open your browser and visit:

```
http://localhost:5173
```
